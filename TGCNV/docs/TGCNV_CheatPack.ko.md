# TGCNV CheatPack 2.10

CheatPack V2.10의 결정·이벤트 메뉴를 TGCNV 내부에 통합했습니다. 원본 CheatPack 폴더는 보존합니다. 기존 TGCNV 실행 도구로 시작하면 적용되며, 별도 CheatPack 모드를 함께 선택할 필요가 없습니다.

## 사용

1. 게임을 다시 실행하고 새 캠페인 또는 기존 저장을 불러옵니다.
2. 정치 화면의 결정 목록에서 **[치트] TGCNV 치트 메뉴 켜기**를 선택합니다.
3. 원하는 국가 선택과 효과를 고릅니다. 아무 대상도 선택하지 않으면 본국에 적용합니다. 선택 범주는 함께 적용할 수 있습니다.
4. 종료할 때 **[치트] TGCNV 치트 메뉴 끄기**를 선택합니다. 대상 선택과 아나키 모드를 끄며, 이미 적용한 효과는 유지합니다.

메뉴 숨기기를 사용한 뒤에는 **[치트] 숨긴 치트 메뉴 다시 표시** 결정으로 복구할 수 있습니다. 새 캠페인에서는 처음부터 꺼져 있으며, 기존 저장에도 다시 실행한 뒤 사용할 수 있습니다. 활성 상태와 대상 선택은 일반 게임 플래그로 저장됩니다.

## 포함된 기능

본국·속국·적국·동맹국·열강·준열강·군소국·비문명국 및 TAG 전환을 통한 대상 지정 기능을 유지합니다. 위신, 문명화, 식자율, 악명, 국고, 전쟁 피로도, 투쟁성, 의식도, 다원성, 호전성, 문화 동화, 이민, 전쟁 명분 생성, 생활 적합도, 핵심 지역, 개혁, 장군, 관계, 정부, 이념, 상원, 기반 시설, 독립·세력권 탈퇴, 병합·속국화, 남북전쟁, 인구 규모·계층, 대전·세계 대전 및 통합 국가 기능을 이식했습니다. 속국 관리에서 독립·핵심 지역 반환·다음 속국 선택을 제공합니다.

기술 메뉴는 현재 TGCNV 정의 300개를 사용합니다. 군사 분야는 육군·해군, 민간 분야는 상업·문화·산업이며 1870년을 기준으로 초기/후기를 구분합니다. 옵션별 기술 수는 전체 300, 초기 군사 30, 후기 군사 90, 초기 민간 55, 후기 민간 125, 식민화 관련 4개입니다. TGCNV의 추가 공군·해군·전략 기술도 전체/해당 분야에 포함됩니다.

이민 명령은 전용 보정을 통해 365일 동안 이민 유인 +100%를 부여합니다. 아나키 모드는 별도로 켜야 하며, 전쟁 중 AI의 점령지 이전을 허용합니다. 현재 지도에 맞게 CSA 생성 기능에서 예전 지도 번호를 제거하고 아메리카 대륙·핵심 지역·노예주 조건과 수도 제외 조건을 사용합니다.

원래 콘솔 이벤트 번호도 유지합니다. 예: `event 777770005` 국고, `event 777770004` 악명, `event 777770050` 기술, `event 777770000` 대상 해제, `event 777770010` 메뉴 숨기기/표시. 일반 메뉴를 통해 사용하는 편이 대상 선택을 확인하기 쉽습니다.

## 호환 조정과 검증

치트 전용 결정·플래그·번역 키·그림 파일은 별도 이름을 사용합니다. TGCNV의 정상적인 국가 통합 상태 플래그는 유지합니다. 기존 이벤트·결정 파일을 덮어쓰지 않습니다. `common/event_modifiers.txt` 끝에 전용 이민 보정만 추가합니다. 원본의 중복 결정, 플래그 명령 오타, 조건문에 들어간 효과, 숨기기 시 남던 속국 선택도 수정했습니다.

GFM 전용 V2ME 자동 정리·국가 해체 모듈과 이에 연결된 이벤트 777770070/071은 이식하지 않았습니다. 이 모듈은 현재 TGCNV에 없는 이벤트와 다른 용도로 사용하는 D01 국가를 전제로 합니다. 속국 관리에 필요한 수동 이벤트 3개만 분리했습니다. 원본의 미완성 `Indev.txt`, 빈 종교 이벤트, AI가 모드를 자동 활성화하는 결정 및 D01 국기는 배포에서 제외했습니다.

엔진 DLL, 64비트 POP/재화 worker, 시간 진행, 모델 지연 로딩, 공군·해군 코드와 종속국 열강 제한은 변경하지 않습니다. 기존 엔진의 종속국 열강 제한은 그대로 적용됩니다.

48개 이벤트, 95개 결정, 한국어 문구 435개 및 기술 300개에 대한 오프라인 참조·구문·메뉴 활성 조건·이미지 바이트·CP949/게임 색상 제어문자 검사를 통과했습니다. 게임 실행·캠페인 조작은 수행하지 않았으며, 실제 화면 표시와 치트 효과 확인은 수동 확인 단계입니다.
