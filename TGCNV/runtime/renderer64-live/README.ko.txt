블루 아카이브 캐릭터 64비트 렌더러
117개 모델 / 1,275개 메시 / 1,146개 텍스처. 몸체·얼굴·무기·헤일로·기병·NPC 포함.
게임은 32비트를 유지하며 캐릭터 그리기 계산과 GPU 자원은 별도 x64 작업자가 담당한다.
완료된 색상과 깊이 타일을 게임의 원래 깊이 버퍼에 합성한다.
초기 준비 중, 입력 불일치, 작업자 오류·지연 또는 프레임 처리 예산 초과 때는 원래 그리기를 사용한다.
공유 메모리 2,102,696바이트. 반환 타일 최대512x512, 대상 해상도 최대1920x1080.
한 요청 대기20ms, 프레임당 처리40ms 예산. 실측 FPS 개선이나 전체 메모리 절약을 보장하지 않는다.
자동 진단 캡처와 shadow 검증은 기본 비활성화한다.
끄기: runtime/data/tgcnv_renderer64_probe.txt에서 render=0을 설정하고 게임을 재시작한다.
원본 XAC·DDS·애니메이션·세이브는 변경하지 않는다.
